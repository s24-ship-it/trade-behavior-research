# QUANT-OMEGA | CFD・FX最高水準の仮想トレーダーの評価仕様

- 作成日: 2026-11-20
- 評価対象: 実在しない規範的な取引プロセス。実測成績・バックテストではない。
- 判断: `RESEARCH_ONLY` / `NO_EMPIRICAL_EVIDENCE` / `NO_LIVE_ORDER`
- 全29カテゴリ、完全版379指標、Lite76指標。原典指標IDを変更しない。
- 無敗・あらゆる地合いで必ず大きな利益: `REJECTED_AS_UNREALISTIC_CLAIM`。
- 高品質とは、**不確実性・費用・市場変化を考慮した生存可能な正の長期期待値の研究・運用**を意味する。

## 評価分類

|分類|意味|目標品質5の扱い|
|---|---|---|
|規範的な運用品質|運用規律、統計的検証、損失制御、執行品質等|5は達成目標。実績ではない|
|条件依存の評価軸|保有時間、方向、時間帯、テクニカル、反実仮想等|固定の高低を決めない|
|心理・認知仮説|気質、認知スタイル、感情、バイアス|人格診断や一律の5点は禁止|
|売買履歴から識別不可|脳活動、神経伝達物質、神経発達特性、生育環境|評価をしない。個人史を推定しない|

## 必須実装

1. H（約定）、P（市場価格）、O（注文・取消）、A（口座）、J（判断日誌）、X（外部指標）を、可能な限り各決定時点で利用可能な時刻と共に取り込む。
2. 分割建て・部分決済・ドテンを再構成。契約倍率、円換算、金利調整額、費用を一致させる。
3. 事前定義した戦略に従いEntry / Exit / SL / TP / Lotを復元し、MFE / MAEを高頻度価格経路で算出する。
4. 銘柄・方向・保有時間・曜日・市場セッション・ボラ・レジーム別に結果を分解する。
5. 損失上限・証拠金余力・NO_TRADEの適用条件を検証する。どの地合いでも売買する義務はない。
6. 多重検定数・試行バージョン・費用・重複時系列ラベルを記録し、期間外/OOSとWalk-forwardで評価する。
7. 売買履歴から性格・心理動機・脳状態・生育歴を断定しない。心理系は仮説として並行説明を提示する。
8. 指標ごとに `観測事実` / `算出` / `統計的関連` / `心理仮説` / `識別不可` を分離する。
9. 数値がない場合、勝率/PF/DD等に例示値を埋めず `未測定` のままにする。
10. 結論は `RESEARCH_ONLY` / `NEEDS_DATA` / `REJECTED` / `SUPPORTED_WITH_LIMITATIONS` のいずれかとする。

## ファイル

- FULL: `CFD_FX_QUANT_OMEGA_FULL_379_evaluated.xlsx` / `.csv`
- LITE: `CFD_FX_QUANT_OMEGA_LITE_76_evaluated.xlsx` / `.csv`
- 説明: `00_模範像`、全指標: `01_個別理想評価`、カテゴリ: `02_カテゴリ構成`。
- 元テンプレ `A_評価` には架空規範の定性的な所見のみ記載。`B_評価` / `C_評価` / `D_評価` は実績入力用に未入力のまま保持。
- `01_個別理想評価` にはB/C/Dの品質評価スコアを参照する式がある。差分は「品質目標との差」であり利益率の差ではない。

## 失敗条件

- 完全無敗・一定利益を保証する主張がある。
- 約定不能やスリッページを除外した後付けの成果を実績と呼ぶ。
- 未来情報を含む指標を予測入力として使う。
- 心理・脳・幼少期などを売買履歴から診断する。
- 小標本、多数の探索、コスト無視の好成績を再現性ある優位性とする。
