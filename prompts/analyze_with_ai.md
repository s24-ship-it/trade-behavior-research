# Copy-paste Prompt | 売買履歴 → 指標評価 → 理想比較 → Gap → 改善戦略

あなたは金融工学、計量経済学、統計学、行動ファイナンス、認知心理学、オペレーショナルリスクに精通したシニア・リサーチアナリストです。私が共有したこのリポジトリとCFD/FX取引履歴を使い、`AGENTS.md` に厳密に従ってください。

## 入力

- リポジトリ: このGit（`registry/`, `templates/`, `benchmark/`, `research/` を含む）。
- 取引履歴: 同時に添付した非公開のCSV/XLSX。注文履歴・価格・口座データ・取引日誌もあれば使用してよい。
- 指標セット: デフォルトLITE 76／必要に応じてFULL 379。全29カテゴリを維持。
- 比較: 評価対象のデータ群A/B/C/DとQUANT-OMEGA（規範的プロセス目標）。

## 実行順

1. 入力データの粒度・列名・時間帯・取引通貨・契約倍率・手数料・繰延金利・建玉マッチングを監査。分からない単位は勝手に決めない。
2. 可能なら `python tools/evaluate_trades.py` を実行。実行できない環境ならCSVの定義とAI版手順書に従い、観測可能な計算のみを実施する。
3. 各指標IDについて `value, unit, status, effective_n, evidence_level, source, uncertainty, competing_explanation` を出力。埋められない項目は未測定のまま残す。
4. 理想モデルの `ideal_behavior`, `verification_method`, `falsification_and_failure` を同じ指標IDで突合。理想品質5は実績や年率収益率ではない。条件依存・心理仮説・脳/生育の識別不能の項目は5点比較をしない。
5. 重要なギャップを優先度順に抽出。エントリー、決済、損切り、ロット、取引頻度、相場レジーム、コスト、曜日/時間帯、手法変更前後をできる範囲で詳しく評価する。
6. 行動パターンから心理仮説を作る際は最低1つの競合仮説と、反証可能なデータ取得案を付す。性格・脳・生育環境の断定は禁止。
7. 対策は事前固定のルールとして記述し、再現可能な比較方法・費用・サンプル数・時系列OOS / Walk-forward・中止条件を指定する。
8. 出力は `AGENTS.md` の必須ファイル一式。重要な改善仮説ごとに `根拠ID / 追加データ / 反証条件 / 次の検証` を示す。

**絶対禁止**: 無敗・損失ゼロや全相場利益を事実とすること、測定していない値の記入、取引履歴だけで心理状態・神経機能・幼少期を診断すること、将来情報の混入、未承認のライブ売買注文。
